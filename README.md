# Jay POS Pro

A modern point-of-sale application for retail and service businesses.

---

## Overview

Jay POS Pro is a web-based point-of-sale system covering billing, inventory and
day-to-day store operations, built as a fast single-page application with a
managed backend.

## Features

- Fast, keyboard-friendly billing counter
- Product and inventory management
- Sales history and reporting
- Configurable tax and pricing rules
- Role-based access for staff and administrators
- Responsive interface for desktop, tablet and counter terminals

## Tech Stack

- **Frontend:** React + TypeScript, built with Vite
- **UI:** shadcn-ui components with Tailwind CSS
- **Backend / data:** Supabase (PostgreSQL, auth, row-level security)
- **Tooling:** ESLint, Vitest
